4. **Vision-Based Verification**

     - `search_merchant_online`: Use Claude web search to resolve abbreviated merchant names (e.g., "SQ *COFFEE" → "Square - Local Coffee Shop Pty Ltd")
     - `lookup_abn`: Query ABR (Australian Business Register) API for ABN/GST registration status
     - `search_cognee_merchant`: Check Cognee for previously learned merchant mappings
     - `store_merchant_mapping`: Save new merchant mapping to Cognee knowledge graph

     a. Check Cognee for existing mapping
     b. If not found, search online for merchant identity
     c. Look up ABN if business name found
     d. Determine GST registration status
     e. Infer correct GST category based on merchant type + ATO rules
     f. Store enrichment in Cognee for future reference
   - Schema for Cognee merchant memory:

