### Agent 2: `v4-architect` — Implement v4 Streaming Pipeline
**Model**: claude-opus-4-6
**Mission**: Create all new v4 pipeline components: streaming unredactor, amount tagger, token map builder, data classification, aggregate tool, and branch manager.

**CREATE these new files**:

1. `server/src/db/neon-connection.ts` — Dual connection pools
```typescript
// Two Drizzle instances: neonDb (production, real data) and neonMaskedDb (AI branch, masked)
// neonMaskedDb connection string is hot-swappable when branch refreshes
// Falls back to local PG if NEON_DATABASE_URL is not set (USE_NEON=false)
```

2. `server/src/services/neon/branch-manager.ts` — NeonBranchManager
- refreshMaskedBranch(): Create new anonymized branch, wait for completion, swap connection pool, delete old branch
- Uses Neon REST API (POST /branch_anonymized, GET /anonymized_status)
- Cron schedule: every 4 hours or on-demand after data import

3. `server/src/services/pipeline/streaming-unredactor.ts` — StreamingUnredactor
- Takes a Map<string, string> (masked -> real) as constructor argument
- transform(chunk: string): string — replaces masked tokens in-flight
- Maintains a buffer of the last N chars (N = max token length) to catch tokens split across chunks
- flush(): string — returns any remaining buffered content
- Used in the streaming loop: `for await (const chunk of agent.stream(input))`

4. `server/src/services/pipeline/amount-tagger.ts` — AmountTagger
- tagAmounts(rows: Record<string, unknown>[], amountColumns: string[]): { taggedRows, tagMap }
- Replaces real amounts with `[[amt:<rowId>_<col>]]` tags
- Stores tag -> real amount mapping in Redis with 1h TTL per session
- resolveTag(tag: string, sessionId: string): Promise<string> — looks up real amount from Redis

5. `server/src/services/pipeline/token-map-builder.ts` — TokenMapBuilder
- buildSessionMap(sessionId, maskedRows, realRows, amountTags): Map<string, string>
- Merges: deterministic name pseudonyms (from comparing prod vs AI branch rows) + amount tags (from AmountTagger)
- The name mappings are STABLE (deterministic masking) so they can be cached long-term
- The amount tags are per-session and expire with Redis TTL

6. `server/src/services/data-classification.ts` — PUBLIC/PRIVATE dataset registry
- PUBLIC_DATASETS: tax_rulings, gst_rules, deduction_patterns (flow freely, no masking)
- PRIVATE_DATASETS: bank_transactions, merchant_data, merchant_mappings, financial_insights, transaction_patterns (must use masked branch)
- getDataSourceForDataset(dataset): 'neon_production' | 'neon_masked' | 'public_docs'
- needsPiiSafetyNet(dataset): boolean

7. `server/src/services/tools/aggregate-tool.ts` — get_exact_totals tool
- Vercel AI SDK tool that queries neonDb (PRODUCTION) for aggregate sums
- Safe because aggregates are inherently k-anonymized (SUM/COUNT/AVG reveal no individual PII)
- Returns exact real totals to Claude so it never does dollar math on masked/tagged data
- Supports: sum, count, avg on transactions, payroll_runs, invoices, bills
- Filters: date_from, date_to, category, group_by
