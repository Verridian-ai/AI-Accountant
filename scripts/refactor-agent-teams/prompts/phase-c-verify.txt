### Test 3: Deterministic Masking Stability
```bash
# Same employee on production vs AI branch

REAL_NAME=$(psql "$NEON_DATABASE_URL" -t -c "SELECT first_name FROM employees WHERE id = '$EMPLOYEE_ID';" | tr -d ' ')
MASKED_NAME=$(psql "$NEON_AI_DATABASE_URL" -t -c "SELECT first_name FROM employees WHERE id = '$EMPLOYEE_ID';" | tr -d ' ')

echo "Real: $REAL_NAME -> Masked: $MASKED_NAME"
# Expected: Different names, but masked name is consistent (deterministic)

# Verify amounts are NOT noised (v4 does not mask amounts in DB)
REAL_AMOUNT=$(psql "$NEON_DATABASE_URL" -t -c "SELECT amount FROM transactions LIMIT 1;" | tr -d ' ')
MASKED_AMOUNT=$(psql "$NEON_AI_DATABASE_URL" -t -c "SELECT amount FROM transactions WHERE id = (SELECT id FROM transactions LIMIT 1);" | tr -d ' ')

echo "Real amount: $REAL_AMOUNT -> Masked amount: $MASKED_AMOUNT"
# Expected: SAME (amounts are not masked in DB — they're tagged at application layer)
```
